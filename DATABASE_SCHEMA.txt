DATABASE SCHEMA - RESTO PILOT
================================

All tables have:
- id: UUID (primary key, auto-generated)
- Standard naming conventions for indexes, unique constraints, foreign keys, etc.

================================
USER MANAGEMENT
================================

Table: users
------------
- id: UUID (primary key)
- telegram_id: BIGINT (unique, not null)
- chat_id: BIGINT (unique, not null)
- full_name: STRING (nullable)
- username: STRING (nullable)
- phone: STRING (nullable)
- is_phone_verified: BOOLEAN (not null, default: false)
- state: STRING(50) (nullable, default: 'IDLE')
- state_data: JSON/JSONB (nullable) - stores conversation context, active operation, collected params
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- last_interaction_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


Table: restaurants
------------------
- id: UUID (primary key)
- name: STRING (not null)
- restaurant_code: STRING (unique, not null)
- owner_user_id: UUID (foreign key -> users.id, on delete: RESTRICT, not null)
- onboarding_status: JSON/JSONB (not null, default: {})
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- last_active_at: TIMESTAMP WITH TIME ZONE (nullable)
- address: STRING (nullable)
- internal_name: STRING (nullable)


Table: restaurant_users
------------------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- user_id: UUID (foreign key -> users.id, on delete: CASCADE, not null)
- role: ENUM('owner', 'staff') (not null)
- joined_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- invited_by: UUID (foreign key -> users.id, on delete: SET NULL, nullable)
- status: ENUM('invited', 'active', 'removed') (not null, default: 'invited')
- Unique constraint: (restaurant_id, user_id)


Table: invite_codes
-------------------
- id: UUID (primary key)
- code: STRING(10) (not null, unique)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- role: ENUM('owner', 'staff') (not null)
- expires_at: TIMESTAMP WITH TIME ZONE (nullable)
- used_at: TIMESTAMP WITH TIME ZONE (nullable)
- created_by: UUID (foreign key -> users.id, on delete: SET NULL, nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


================================
SUPPLIER MANAGEMENT
================================

Table: suppliers
----------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- name: STRING (not null)
- contact_name: STRING (nullable)
- contact_email: STRING (nullable)
- contact_phone: STRING (nullable)
- language: STRING (nullable)
- currency: STRING (nullable)
- lead_time_days: INTEGER (nullable)
- notes: STRING (nullable)
- is_active: BOOLEAN (not null, default: true)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- updated_at: TIMESTAMP WITH TIME ZONE (not null, default: now(), auto-update)


Table: supplier_items
---------------------
- id: UUID (primary key)
- supplier_id: UUID (foreign key -> suppliers.id, on delete: CASCADE, not null)
- product_id: UUID (foreign key -> products.id, on delete: CASCADE, nullable)
- supplier_sku: STRING (nullable)
- supplier_name_raw: STRING (not null)
- pack_size_text: STRING (nullable)
- unit_basis: ENUM('kg', 'pack', 'piece') (nullable)
- min_order_qty: NUMERIC (nullable)
- status: ENUM('active', 'discontinued') (not null)
- source_document_id: UUID (foreign key -> documents.id, on delete: SET NULL, nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


Table: supplier_prices
----------------------
- id: UUID (primary key)
- supplier_item_id: UUID (foreign key -> supplier_items.id, on delete: CASCADE, not null)
- price: NUMERIC (not null)
- currency: STRING (not null)
- price_type: ENUM('standard', 'promo', 'special') (not null)
- valid_from: TIMESTAMP WITH TIME ZONE (not null)
- valid_to: TIMESTAMP WITH TIME ZONE (nullable)
- min_qty: NUMERIC (nullable)
- source_document_id: UUID (foreign key -> documents.id, on delete: SET NULL, nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


================================
PRODUCT MANAGEMENT
================================

Table: products
--------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- name_en: STRING (not null)
- name_local: STRING (nullable)
- category: STRING (nullable)
- sub_category: STRING (nullable)
- storage_type: ENUM('frozen', 'chilled', 'dry') (nullable)
- default_unit: ENUM('kg', 'pack', 'piece') (nullable)
- default_unit_size: NUMERIC (nullable)
- is_active: BOOLEAN (not null, default: true)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- updated_at: TIMESTAMP WITH TIME ZONE (not null, default: now(), auto-update)


Table: product_aliases
----------------------
- id: UUID (primary key)
- product_id: UUID (foreign key -> products.id, on delete: CASCADE, not null)
- supplier_id: UUID (foreign key -> suppliers.id, on delete: CASCADE, nullable)
- alias_text: STRING (not null)
- confidence: ENUM('auto', 'manual') (not null)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


================================
INVOICE MANAGEMENT
================================

Table: invoices
---------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- supplier_id: UUID (foreign key -> suppliers.id, on delete: CASCADE, not null)
- invoice_number: STRING (not null)
- invoice_date: TIMESTAMP WITH TIME ZONE (not null)
- due_date: TIMESTAMP WITH TIME ZONE (nullable)
- currency: STRING (not null)
- subtotal: NUMERIC (not null)
- tax: NUMERIC (not null)
- total: NUMERIC (not null)
- document_id: UUID (foreign key -> documents.id, on delete: SET NULL, nullable)
- status: ENUM('received', 'paid', 'disputed') (not null)
- authorized_by_user_id: UUID (foreign key -> users.id, on delete: SET NULL, nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


Table: invoice_line_items
-------------------------
- id: UUID (primary key)
- invoice_id: UUID (foreign key -> invoices.id, on delete: CASCADE, not null)
- supplier_id: UUID (foreign key -> suppliers.id, on delete: CASCADE, not null)
- supplier_item_id: UUID (foreign key -> supplier_items.id, on delete: SET NULL, nullable)
- product_id: UUID (foreign key -> products.id, on delete: SET NULL, nullable)
- description_raw: STRING (not null)
- quantity: NUMERIC (not null)
- unit: STRING (not null)
- unit_price: NUMERIC (not null)
- line_total: NUMERIC (not null)
- currency: STRING (not null)
- tax_amount: NUMERIC (not null)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


================================
INVENTORY MANAGEMENT
================================

Table: inventory_locations
--------------------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- name: STRING (not null)
- type: ENUM('storage', 'kitchen') (not null)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- updated_at: TIMESTAMP WITH TIME ZONE (not null, default: now(), auto-update)


Table: inventory_batches
------------------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- product_id: UUID (foreign key -> products.id, on delete: CASCADE, not null)
- supplier_id: UUID (foreign key -> suppliers.id, on delete: CASCADE, not null)
- invoice_line_item_id: UUID (foreign key -> invoice_line_items.id, on delete: SET NULL, nullable)
- quantity: NUMERIC (not null)
- unit: STRING (not null)
- unit_cost: NUMERIC (not null)
- received_date: TIMESTAMP WITH TIME ZONE (not null)
- expiry_date: TIMESTAMP WITH TIME ZONE (nullable)
- location_id: UUID (foreign key -> inventory_locations.id, on delete: SET NULL, nullable)
- status: ENUM('available', 'consumed', 'expired') (not null)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- updated_at: TIMESTAMP WITH TIME ZONE (not null, default: now(), auto-update)


Table: inventory_movements
--------------------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- inventory_batch_id: UUID (foreign key -> inventory_batches.id, on delete: CASCADE, not null)
- movement_type: ENUM('receive', 'consume', 'waste', 'adjust') (not null)
- quantity: NUMERIC (not null)
- reason: STRING (nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


================================
PRICING & DISPUTES
================================

Table: price_comparisons
------------------------
- id: UUID (primary key)
- invoice_line_item_id: UUID (foreign key -> invoice_line_items.id, on delete: CASCADE, not null)
- supplier_price_id: UUID (foreign key -> supplier_prices.id, on delete: CASCADE, not null)
- expected_price: NUMERIC (not null)
- actual_price: NUMERIC (not null)
- delta: NUMERIC (not null)
- status: ENUM('ok', 'warning', 'dispute') (not null)
- reviewed_by: UUID (foreign key -> users.id, on delete: SET NULL, nullable)
- reviewed_at: TIMESTAMP WITH TIME ZONE (nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


Table: supplier_disputes
------------------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- invoice_id: UUID (foreign key -> invoices.id, on delete: CASCADE, not null)
- reason: STRING (not null)
- status: ENUM('open', 'resolved') (not null)
- resolution_notes: STRING (nullable)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- updated_at: TIMESTAMP WITH TIME ZONE (not null, default: now(), auto-update)


================================
DOCUMENT MANAGEMENT
================================

Table: documents
----------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- supplier_id: UUID (foreign key -> suppliers.id, on delete: SET NULL, nullable)
- doc_type: ENUM('catalogue', 'price_list', 'promo', 'invoice') (not null)
- language: STRING (nullable)
- effective_date: TIMESTAMP WITH TIME ZONE (nullable)
- file_url: STRING (not null) - Telegram file_id
- notes: STRING (nullable)
- uploaded_at: TIMESTAMP WITH TIME ZONE (not null, default: now())


Table: file_processing_staging
-------------------------------
- id: UUID (primary key)
- restaurant_id: UUID (foreign key -> restaurants.id, on delete: CASCADE, not null)
- user_id: UUID (foreign key -> users.id, on delete: CASCADE, not null)
- document_id: UUID (foreign key -> documents.id, on delete: SET NULL, nullable)
- processing_type: ENUM('invoice', 'price_list', 'inventory') (not null)
- extracted_data_json: JSON/JSONB (not null)
- product_alias_matches_json: JSON/JSONB (not null, default: {})
- status: ENUM('pending_review', 'confirmed', 'cancelled', 'awaiting_supplier', 'awaiting_currency') (not null, default: 'pending_review')
- authorized_by_user_id: UUID (foreign key -> users.id, on delete: SET NULL, nullable)
- confirmed_at: TIMESTAMP WITH TIME ZONE (nullable)
- cancelled_at: TIMESTAMP WITH TIME ZONE (nullable)
- expires_at: TIMESTAMP WITH TIME ZONE (not null, default: now() + 7 days)
- created_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- updated_at: TIMESTAMP WITH TIME ZONE (not null, default: now(), auto-update)


================================
TELEGRAM & MESSAGING
================================

Table: telegram_sessions
------------------------
- id: UUID (primary key)
- chat_id: BIGINT (not null)
- started_at: TIMESTAMP WITH TIME ZONE (not null)
- last_activity_at: TIMESTAMP WITH TIME ZONE (not null)
- flush_at: TIMESTAMP WITH TIME ZONE (not null)
- status: ENUM('open', 'processing', 'closed') (not null)
- hint_command: STRING (nullable)
- closed_at: TIMESTAMP WITH TIME ZONE (nullable)
- ack_sent_at: TIMESTAMP WITH TIME ZONE (nullable)
- Indexes:
  - ix_telegram_sessions_chat_id_status (chat_id, status)
  - ix_telegram_sessions_status_flush_at (status, flush_at)


Table: telegram_messages
------------------------
- id: UUID (primary key)
- session_id: UUID (foreign key -> telegram_sessions.id, not null)
- chat_id: BIGINT (not null)
- user_id: UUID (foreign key -> users.id, not null)
- telegram_id: BIGINT (foreign key -> users.telegram_id, not null)
- message_id: BIGINT (not null)
- update_id: BIGINT (unique, not null)
- received_at: TIMESTAMP WITH TIME ZONE (not null)
- text: STRING (nullable)
- caption: STRING (nullable)
- file_id: STRING (nullable)
- file_unique_id: STRING (nullable)
- file_kind: STRING (nullable)
- mime: STRING (nullable)
- filename: STRING (nullable)
- size: BIGINT (nullable)
- Indexes:
  - ix_telegram_messages_session_id (session_id)
  - ix_telegram_messages_chat_id_received_at (chat_id, received_at)
  - ix_telegram_messages_file_unique_id (file_unique_id)


Table: telegram_outgoing_messages
----------------------------------
- id: UUID (primary key)
- session_id: UUID (foreign key -> telegram_sessions.id, not null)
- chat_id: BIGINT (not null)
- kind: STRING (not null)
- text: STRING (not null)
- telegram_message_id: BIGINT (nullable)
- llm_call_id: UUID (foreign key -> llm_calls.id, nullable)
- sent_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- Indexes:
  - ix_telegram_outgoing_messages_session_id_sent_at (session_id, sent_at)
  - ix_telegram_outgoing_messages_chat_id_sent_at (chat_id, sent_at)
  - ix_telegram_outgoing_messages_kind_sent_at (kind, sent_at)


================================
LLM & PROCESSING
================================

Table: llm_calls
----------------
- id: UUID (primary key)
- session_id: UUID (foreign key -> telegram_sessions.id, not null)
- chat_id: BIGINT (nullable)
- purpose: STRING (not null)
- model: STRING (not null)
- openrouter_generation_id: STRING (unique, nullable)
- upstream_id: STRING (nullable)
- provider_name: STRING (nullable)
- prompt_tokens: BIGINT (nullable)
- completion_tokens: BIGINT (nullable)
- total_tokens: BIGINT (nullable)
- latency_ms: BIGINT (nullable)
- total_cost_usd: NUMERIC(18, 9) (nullable)
- cache_discount_usd: NUMERIC(18, 9) (nullable)
- upstream_inference_cost_usd: NUMERIC(18, 9) (nullable)
- cost_backfilled_at: TIMESTAMP WITH TIME ZONE (nullable)
- openrouter_generation_json: JSON/JSONB (nullable)
- requested_at: TIMESTAMP WITH TIME ZONE (not null, default: now())
- error: STRING (nullable)
- Indexes:
  - ix_llm_calls_session_id_requested_at (session_id, requested_at)
  - ix_llm_calls_chat_id_requested_at (chat_id, requested_at)
  - ix_llm_calls_purpose_requested_at (purpose, requested_at)


Table: processing_events
------------------------
- id: UUID (primary key)
- session_id: UUID (foreign key -> telegram_sessions.id, not null)
- at: TIMESTAMP WITH TIME ZONE (not null)
- event: STRING (nullable)
- payload_json: STRING (nullable)
- error: STRING (nullable)
- Index:
  - ix_processing_events_session_id_at (session_id, at)


================================
RELATIONSHIPS SUMMARY
================================

Core Relationships:
- users -> restaurants (owner_user_id)
- restaurants -> restaurant_users (many-to-many via junction table)
- restaurants -> suppliers (one-to-many)
- restaurants -> products (one-to-many)
- restaurants -> invoices (one-to-many)
- restaurants -> inventory_locations (one-to-many)
- restaurants -> inventory_batches (one-to-many)
- restaurants -> inventory_movements (one-to-many)
- restaurants -> supplier_disputes (one-to-many)
- restaurants -> documents (one-to-many)
- restaurants -> file_processing_staging (one-to-many)

Supplier Relationships:
- suppliers -> supplier_items (one-to-many)
- suppliers -> supplier_prices (via supplier_items)
- suppliers -> invoices (one-to-many)
- suppliers -> documents (one-to-many)

Product Relationships:
- products -> product_aliases (one-to-many)
- products -> supplier_items (one-to-many)
- products -> invoice_line_items (one-to-many)
- products -> inventory_batches (one-to-many)

Invoice Relationships:
- invoices -> invoice_line_items (one-to-many)
- invoices -> supplier_disputes (one-to-many)
- invoice_line_items -> inventory_batches (one-to-many)
- invoice_line_items -> price_comparisons (one-to-many)

Inventory Relationships:
- inventory_batches -> inventory_movements (one-to-many)
- inventory_locations -> inventory_batches (one-to-many)

Document Relationships:
- documents -> supplier_items (source_document_id)
- documents -> supplier_prices (source_document_id)
- documents -> invoices (document_id)
- documents -> file_processing_staging (document_id)

Telegram Relationships:
- telegram_sessions -> telegram_messages (one-to-many)
- telegram_sessions -> telegram_outgoing_messages (one-to-many)
- telegram_sessions -> llm_calls (one-to-many)
- telegram_sessions -> processing_events (one-to-many)
- users -> telegram_messages (one-to-many)
- llm_calls -> telegram_outgoing_messages (one-to-many)
